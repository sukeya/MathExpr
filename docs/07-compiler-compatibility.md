# Section 07: Compiler Compatibility

[Back to index](index.md)

[Previous](06-compilation.md) | [Index](index.md) | [Next](08-built-in-operations-and-functions.md)

ExprTk has been built error and warning free using the following set of C++ compilers:

1. GNU Compiler Collection (3.5+)
1. Clang/LLVM (1.1+)
1. Microsoft Visual Studio C++ Compiler (_MSC_VER 1930+, Visual Studio 2022+)
1. Intel C++ Compiler (8.x+)
1. AMD Optimizing C++ Compiler (1.2+)
1. Nvidia C++ Compiler (19.x+)
1. PGI C++ (10.x+)
1. Circle C++ (circa: b81c37d2bb227c)
1. IBM XL C/C++ (9.x+)
1. C++ Builder (XE4+)
