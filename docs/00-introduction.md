MathExpr is a modern fork of The C++ Mathematical Expression Toolkit Library (ExprTk) which is a simple to use, easy to integrate and extremely efficient run-time mathematical expression parsing and evaluation engine. The parsing engine supports numerous forms of functional and logic processing semantics and is easily extensible.
